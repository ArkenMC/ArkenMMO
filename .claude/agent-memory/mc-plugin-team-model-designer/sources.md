- Images can be viewed: download with curl into a new scratchpad folder, then Read the file (2026-11-26).
- What each viewed reference taught, with URLs: `design/skill-tree-visual-research.md` (2026-11-26).
- Wikimedia: search `commons.wikimedia.org/w/api.php?action=query&generator=search&gsrnamespace=6&prop=imageinfo&iiprop=url&iiurlwidth=960` (2026-11-26).
- Fandom images return HTML unless the URL ends `&format=original` and sends image `Accept` and `Referer` headers (2026-11-26).
- Dead ends: wynncraft.wiki.gg and warcraft.wiki.gg return 403 (2026-11-26, volatile).
